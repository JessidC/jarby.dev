Projects

Public rebuild

rag-eval-bench

A bench that decides whether a RAG change ships: a golden set with questions the docs can't answer, an LLM judge, a validator that catches invented citations and numbers, and a paired McNemar test behind a CI gate. It runs on the public Odoo 18 docs.

What it found: hybrid retrieval beat dense by 12.5 points (p = 0.02). With a judge from another model family the gain drops to 9.7 points and is no longer significant. A reranker added nothing and pushed p95 latency from 2.5 s to 8.3 s, so it doesn't ship.

Unlike production, the main judge is the same model that answers, and the golden set was drafted by a model and not yet reviewed by a person. The README lists both limits. Production does use a reranker, on a different corpus of Spanish manuals with scanned pages. What the bench shows is that the call has to be measured on each corpus.

Public rebuild

support-learning-loop

The improvement loop from chapter 6, rebuilt on public data. A support bot hands the chats it can't solve to people, a judge from another model family turns the agents' answers into candidate entries, a grounding check rejects anything the agent didn't say, and an expert approves each one before the bot can use it.

19%61%chats resolved correctly
68%21%chats handed to a person
41%23%partial or wrong among answers shown

Measured on 330 held-out chats from the ABCD dataset, with the same bot and only the knowledge base changing. In this run the judge approved every entry on its own, with no person reading them, so the numbers show the loop without its safety net. The README shows the cost. The bot started answering 5 of 80 chats that needed a person.
